Инструкция по подключению

  1. Откройте Настройки в Telegram.
  2. Перейдите в раздел Telegram для бизнеса.
  3. Выберите Чат-боты и введите DelixorBot.
  4. Нажмите Добавить для подключения
  5. В разрешениях отметьте все пункты раздела Сообщения.
